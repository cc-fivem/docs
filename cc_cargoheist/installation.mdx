## Requirements

- A FiveM server already running [cc_heistcontracts](/cc_heistcontracts/installation).
- [ox_lib](https://github.com/overextended/ox_lib), [oxmysql](https://github.com/overextended/oxmysql), [ox_target](https://github.com/overextended/ox_target), [ox_inventory](https://github.com/overextended/ox_inventory).
- A working `cc_lib` resource.

<Note>
  Unlike the other heist modules (which only escrow-ignore `shared/**/*`), `cc_cargoheist` declares **ox_target** and **ox_inventory** as direct `fxmanifest.lua` dependencies. If you're on a different target/inventory framework you'll need to swap those out before the resource will boot.
</Note>

## Steps

<Steps>
  <Step title="Place the resource">
    Copy `cc_cargoheist` into a resources directory the server loads. The repo ships under `resources/[cc]/cc_cargoheist/`.
  </Step>
  <Step title="Add the angle_grinder item to ox_inventory">
    `angle_grinder` is **not** part of the default ox_inventory items list. Add it to `ox_inventory/data/items.lua`:

    ```lua
    ['angle_grinder'] = {
        label  = 'Angle Grinder',
        weight = 2400,
        stack  = false,
        client = { image = 'angle_grinder.png' },
    },
    ```

    Drop an `angle_grinder.png` image into `ox_inventory/web/images/`. You can reuse the in-game Tuner DLC grinder prop image (`tr_prop_tr_grinder_01a`) or any cordless-grinder render.
  </Step>
  <Step title="Add the angle grinder to the cc_heistcontracts marketplace">
    Open `cc_heistcontracts/shared/marketplace_config.lua` and add the grinder under the `tools` category so players can buy it:

    ```lua
    tools = {
        label = 'Tools',
        items = {
            { id = 'electric_drill', name = 'Cordless Drill', price = 450, levelRequired = 1 },
            { id = 'angle_grinder',  name = 'Angle Grinder',  price = 900, levelRequired = 1 },
        },
    },
    ```

    Restart `cc_heistcontracts` after editing. Without this listing, players have no in-script way to acquire the item.
  </Step>
  <Step title="Ensure after cc_heistcontracts">
    Order in `server.cfg`:

    ```
    ensure oxmysql
    ensure ox_lib
    ensure ox_inventory
    ensure ox_target
    ensure cc_lib
    ensure cc_heistcontracts
    ensure cc_cargoheist
    ```

    `cc_cargoheist`'s `fxmanifest.lua` declares all four upstream dependencies, so FXServer enforces this.
  </Step>
  <Step title="(Optional) Tune the guard fight">
    `shared/config.lua` controls the guard squad:

    ```lua
    cfg.guards = {
        minCount = 4,
        maxCount = 8,
        model    = `csb_mweather`,
        weapon   = `WEAPON_CARBINERIFLE`,
        health   = 150,
        armor    = 100,
        accuracy = 25,
        disableCriticalHits = false,
    }
    ```

    Lower `accuracy` or `armor` for an easier fight; raise `minCount` for a harder one.
  </Step>
  <Step title="Verify in-game">
    1. Use a `heist_tablet`. **Cargo Container Raid** should drip into the marketplace.
    2. Buy it for 1,500 VICE, hold an `angle_grinder`, head to LSIA Cargo Yard.
    3. Clear guards, walk up to a container's lock, use the ox_target option to begin the cut scene.

    <Tip>
      The grinder scene is anchored to the Tuner DLC asset pack. If your server has Tuner DLC streaming disabled, the container/lock props won't render — re-enable the DLC or swap `cfg.containerModel` / `cfg.lockModel` to a custom prop.
    </Tip>
  </Step>
</Steps>

## No SQL migrations

`cc_cargoheist` has no schema. Completion state lives in `cc_heistcontracts.heist_profiles`. Make sure the three `cc_heistcontracts` migrations have already been applied.

## Customising loot

`shared/rewards.lua` is the **global loot table**. When `cfg.use_global_loot_table = true` (default), the rolled total is split across every container at the site.

```lua
return {
    containers = {
        { type = 'item', item = 'black_money', amount = { min = 4000, max = 8000 } },
    },
}
```

For per-container loot, set `use_global_loot_table = false` in `shared/config.lua` and define a `rewards` table on each container in `shared/locations/lsia_docks.lua`.

## Concurrency

The contract uses the default `maxConcurrent` cap (= number of locations = 1). Only **one crew can run the LSIA site at a time** server-wide. Uncomment and raise `maxConcurrent` in `shared/contract.lua` if you add more locations and want to allow parallel runs:

```lua
-- maxConcurrent = 1,
```
