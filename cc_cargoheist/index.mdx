`cc_cargoheist` is a heist module that plugs into [cc_heistcontracts](/cc_heistcontracts/index). It registers a single contract — **Cargo Container Raid** — at the LSIA Cargo Yard. Crews clear armed guards, cut shipping containers open with an angle grinder, and loot what's inside.

Everything in this page is a **default**. All of it lives in plain Lua files in `shared/` and is meant to be edited.

## Required items

Players need these in their inventory before the dashboard will let them press **Start**. The list lives in `shared/contract.lua` under `itemsRequired` — add, remove, or change quantities freely.

| Item id | Inventory label | Default role in the run |
| --- | --- | --- |
| `angle_grinder` | Angle Grinder | Cuts container locks |

<Note>
  The `angle_grinder` item is **not** shipped in the default `ox_inventory/data/items.lua`. You need to add it — see the [installation guide](/cc_cargoheist/installation).
</Note>

## Contract defaults

Defined in `shared/contract.lua`. Every field is editable.

| Field | Default | What it does |
| --- | --- | --- |
| `id` | `cargo_container` | Internal contract id |
| `difficulty` | `easy` | Display tag in the dashboard |
| `weight` | `1.0` | Rarity weight for marketplace drips |
| `levelRequired` | `1` | Minimum heist level to purchase |
| `price` | `1500` | VICE cost to buy the slot |
| `crewSize` | `{ min = 1, max = 4 }` | Solo allowed by default |
| `duration` | `1200` | Soft cap in seconds before the slot auto-fails |
| `cooldown` | `90` | Server-wide cooldown after each completion |
| `reward` | `{ vice = 1500, xp = 250 }` | Credited automatically on success |
| `locations` | 1 | `lsia_docks` — LSIA Cargo Yard |
| `maxConcurrent` | (defaults to # locations) | How many crews can run this contract at once across all locations |

Per-site coordinates and container placements live in `shared/locations/<id>.lua`.

## Loot table

`shared/rewards.lua` defines the global loot. When `cfg.use_global_loot_table = true` (default), the rolled total is split across every container at the site.

```lua
return {
    containers = {
        { type = 'item', item = 'black_money', amount = { min = 4000, max = 8000 } },
    },
}
```

Set `cfg.use_global_loot_table = false` to define `rewards` per-container inside each site file under `shared/locations/`.

## Other tunables

`shared/config.lua`:

| Field | Default | What it does |
| --- | --- | --- |
| `cfg.use_global_loot_table` | `true` | If `false`, expects per-container `rewards` |
| `cfg.debug` | `true` | Verbose logs (turn off for production) |
| `cfg.containerModel` / `cfg.collisionModel` / `cfg.lockModel` | Tuner DLC props | Swap to custom models if Tuner DLC is disabled |
| `cfg.guards` | `{ minCount=4, maxCount=8, model=csb_mweather, weapon=carbinerifle, health=150, armor=100, accuracy=25 }` | Guard squad config |
| `cfg.grinder` | scripted scene config | Anim dict, item id (`hacking_device` held during cut), sparks, audio |
| `cfg.lootProp` | `ex_prop_crate_ammo_sc` | Prop spawned inside each cut container |
| `cfg.timings.lootAnimMs` | `4000` | Grab cargo animation length |
| `cfg.dispatch` | `function(coords) ... end` | Police alert fired when the first guard takes damage |
