Everything `cc_fishing` exposes for tuning. All paths are relative to the resource root.

## Modules

`shared/config.lua` → `cfg.modules`. Toggle features on or off. Restart `cc_fishing` after editing.

```lua
cfg.modules = {
    level              = true,
    sales              = true,
    equipment          = true,
    leaderboard        = true,
    tournaments        = true,
    active_tournaments = true,
    challenges         = true,
    rental             = true,
    nets               = true,
    treasure           = true,
}
```

NPC interactions, UI tabs, and server logic for each module gate off the same flag — no extra cleanup needed when turning one off.

## NPC placement

`shared/config.lua` → `cfg.npc`. Change the model or coords and restart the resource; blips, peds, and target zones rebuild from this block.

```lua
cfg.npc = {
    fishing = {
        model       = 'a_m_y_beach_01',
        coords      = vector4(1302.95, 4228.7, 33.91, 18.89),
        blip_sprite = 780,
        blip_color  = 3,
        blip_scale  = 0.60,
    },
    pawnshop = {
        model       = 'cs_nervousron',
        coords      = vector4(-1459.56, -413.97, 35.74, 161.5),
        blip_sprite = 500,
        blip_color  = 5,
        blip_scale  = 0.60,
    },
}
```

## Payment sources

`shared/config.lua` → `cfg.money`. Each entry is `'cash'` or `'bank'`.

```lua
cfg.money = {
    buy_equipment     = 'bank',
    boat_rental       = 'bank',
    tournament_reward = 'bank',
    challenge_reward  = 'bank',
    sell_treasure     = 'cash',
    sell_fish         = 'cash',
}
```

## Key tunables

All in `shared/config.lua`. Edit and restart.

| Field | Default | What it does |
| --- | --- | --- |
| `cfg.cast.wait_min_seconds` / `wait_max_seconds` | `25` / `40` | Bite-wait window before any level reduction |
| `cfg.cast.wait_floor_seconds` | `15` | Hard floor on bite wait after level reduction |
| `cfg.length_skew` | `2.5` | Catch-length distribution. Higher = trophies are rarer |
| `cfg.level_thresholds` | 30 tiers | XP totals per level. Edit to reshape progression |
| `cfg.market.floor` / `ceiling` | `0.75` / `1.25` | Pawnshop multiplier bounds |
| `cfg.market.impact` / `recovery` | `0.10` / `0.05` | Per-sale push toward floor; per-tick recovery |
| `cfg.tournament.duration_days` | `7` | Weekly tournament length |
| `cfg.tournament.prizes` | `{ 10000, 5000, 2500 }` | Top-3 prize pool in bank |
| `cfg.active_tournament.daily_hours` | `{ 12, 20 }` | Server-clock start times for active tournaments |
| `cfg.active_tournament.zones` | 8 zones | Live zones eligible for active tournaments |
| `cfg.treasure.base_chance` | `0.5` | % chance per catch (before level/bait bonuses) |
| `cfg.treasure.bait_bonus_mult` | `15.0` | Treasure-chance multiplier when using `treasure_bait` |
| `cfg.nets.catch_interval` | `1800` | Seconds between net catch rolls |
| `cfg.nets.max_per_player` | `2` | Per-player net cap |
| `cfg.boat.rental_price` / `return_refund` | `500` / `0.25` | Boat rental price and refund fraction on return |
| `cfg.rod.random_break` | `true` | If `false`, rods only break at zero durability |

## Customisable Lua files

Each file is a plain Lua list — add, remove, reorder. Restart `cc_fishing` after editing.

| File | What's in it |
| --- | --- |
| `shared/fish.lua` | All catchable fish: tier, length range, XP, base price, zone preferences |
| `shared/tiers.lua` | Tier display labels, order, icons |
| `shared/zones.lua` | Fishing zones (polygons), per-zone boost/blacklist, treasure multiplier |
| `shared/equipment.lua` | Rods, baits, shop items — prices, level gates, boosts |
| `shared/challenges.lua` | Daily challenge pool — match predicates, rewards, level gates |
| `shared/treasures.lua` | Treasure loot tables and per-tier safe payouts |
