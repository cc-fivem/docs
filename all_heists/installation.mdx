Follow this page if you own **all four** heist modules — `cc_fleecaheist`, `cc_paletoheist`, `cc_pacificheist`, and `cc_cargoheist`. Each module also ships its own installation page; this guide just consolidates the shared steps (inventory items, gabz mapdata, ensure order) so you only edit each file once.

## Requirements

- A FiveM server already running [cc_heistcontracts](/cc_heistcontracts/installation) — all four modules register contracts against it.
- [ox_lib](https://github.com/overextended/ox_lib) and [oxmysql](https://github.com/overextended/oxmysql).
- A working `cc_lib` resource.
- An inventory system (defaults assume **ox_inventory**).
- [ox_target](https://github.com/overextended/ox_target) and [ox_inventory](https://github.com/overextended/ox_inventory) — `cc_cargoheist` declares both as hard `fxmanifest.lua` dependencies.
- Streaming enabled — `cc_pacificheist` ships custom jammer assets under `stream/`.

## Steps

<Steps>
  <Step title="Place the resources">
    Copy all four resources into a directory the server loads. The repo ships them under `resources/[cc]/`:

    ```
    resources/[cc]/cc_fleecaheist/
    resources/[cc]/cc_paletoheist/
    resources/[cc]/cc_pacificheist/
    resources/[cc]/cc_cargoheist/
    ```

    The `stream/` folder inside `cc_pacificheist` must travel with it — the custom jammer props live there.
  </Step>
  <Step title="Add the inventory items">
    Every item used by the four heists in one block. Drop the matching images into your inventory's images folder (filenames must match the item name / `image` field).

    <Tabs>
      <Tab title="ox_inventory">
        Add the following items to `ox_inventory/data/items.lua`

        ```lua
        -- Fleeca
        hacking_device = { label = 'DataJack', weight = 600, stack = false },
        laptop_cheap = { label = 'Refurb LiteBook', weight = 2500, stack = false },
        electric_drill = { label = 'Cordless Drill', weight = 1800, stack = false },

        -- Paleto (hacking_device + electric_drill above are shared)
        laptop_pro = { label = 'Jackbox Pro', weight = 2800, stack = false },
        frequency_tuner = { label = 'Signal Modulator', weight = 250 },

        -- Pacific (electric_drill above is shared)
        laptop_elite = { label = 'BlackBook Mk-III', weight = 3200, stack = false },
        signal_jammer = { label = 'Signal Jammer', weight = 400 },
        thermite = { label = 'Thermite Charge', weight = 800 },

        -- Cargo
        angle_grinder = { label = 'Angle Grinder', weight = 2400, stack = false },
        ```

        <Note>
          The `weapon_pistol`, `weapon_smg`, `weapon_digiscanner`, and `weapon_assaultrifle` requirements are standard ox_inventory weapons — no extra config needed if you're on the stock weapons list.
        </Note>
        <Note>
          In the shipped Qbox `items.lua` the `thermite` entry exists but is **commented out** at line ~830. Uncomment it before launching `cc_pacificheist`.
        </Note>
      </Tab>

  <Step title="List the angle grinder in the cc_heistcontracts marketplace">
    `angle_grinder` is the only heist tool that isn't sold by default. Open `cc_heistcontracts/shared/marketplace_config.lua` and add it under the `tools` category:

    ```lua
    tools = {
        label = 'Tools',
        items = {
            { id = 'electric_drill', name = 'Cordless Drill', price = 450, levelRequired = 1 },
            { id = 'angle_grinder',  name = 'Angle Grinder',  price = 900, levelRequired = 1 },
        },
    },
    ```

    Restart `cc_heistcontracts` after editing. Without this listing, players have no in-script way to acquire the grinder for `cc_cargoheist`.
  </Step>

    `cc_cargoheist` doesn't need gabz changes — its LSIA container site is anchored to the Tuner DLC asset pack, not a gabz interior.
  </Step>
  <Step title="Ensure after cc_heistcontracts">
    Final order in `server.cfg`:

    ```
    ensure oxmysql
    ensure ox_lib
    ensure ox_inventory
    ensure ox_target
    ensure cc_lib
    ensure cc_heistcontracts
    ensure cc_fleecaheist
    ensure cc_paletoheist
    ensure cc_pacificheist
    ensure cc_cargoheist
    ```

    Each module's `fxmanifest.lua` declares `cc_heistcontracts` as a dependency, so FXServer will refuse to start any of them before the parent is up. Wrong order = `No such export RegisterContract in resource cc_heistcontracts`.
  </Step>
  <Step title="(Optional) Tune the police gate">
    Fleeca is the only heist with a stock police-count gate. Edit `cc_fleecaheist/shared/contract.lua`:

    ```lua
    requiredPolice = { jobs = { 'police' }, count = 2 }
    ```

    Set `count = 0` (or remove the field) to disable the gate for testing.
  </Step>
  <Step title="Verify in-game">
    1. Use a `heist_tablet` to open the dashboard.
    2. With drips on default (3 min), all four contracts roll into the marketplace within a few intervals. Lower `config.rotation.dripIntervalMs` in `cc_heistcontracts/shared/config.lua` (e.g. `5 * 1000`) and restart `cc_heistcontracts` to see them faster.
    3. Each contract has its own level gate — Fleeca `1`, Paleto `3`, Pacific `5`, Cargo `1`. Use `/heist:grantxp <playerId> <amount>` if you've enabled the admin command.
    4. Watch the server console on first Pacific run for `Streaming pacificheist resource 'cc_jammer.ytyp'` — no error means the custom jammer props are loading.

    <Tip>
      Setting `cfg.debug = true` in each heist's `shared/config.lua` bypasses level / police / cooldown gates so you can chain runs while testing.
    </Tip>
  </Step>
</Steps>
